## Key Principles to Remember

**Deep Research**:
- Challenges claims, doesn't echo marketing
- Surfaces trade-offs and limitations explicitly
- Assesses applicability to SPECIFIC context
- Provides honest "NO" answers when appropriate
- Goes beyond "what" to "how" and "why"

**10 Research Spectra**:
1. Fundamentals - What it is, why it exists
2. Architecture - How it works internally
3. Technical Deep-Dive - Advanced techniques, algorithms
4. Academic Research - Papers, theoretical foundation
5. Integration - Prerequisites, adoption path
6. Performance - Benchmarks (realistic, not marketing)
7. Use Cases - Specific applications, when to use
8. Applicability - When to use AND when NOT to use
9. Implementation - Code examples, production patterns
10. Critical FAQ - Honest Q&A, including "NO" answers

**Critical Assessment**:
- Source diversity (not just vendor claims)
- Trade-off identification (nothing is free)
- Limitation mining (what they don't advertise)
- Comparative analysis (never isolated evaluation)
- Applicability to YOUR context (not generic)

**Depth Calibration**:
- Never heard of it → HIGH fundamentals
- Evaluation goal → HIGH applicability
- Learning goal → Balanced depth
- Research-driven → HIGH academic depth
- Engineering-focused → HIGH implementation depth

**Validation Targets**:
- All 10 spectra covered
- All critical questions answered
- Limitations as prominent as benefits
- At least 1 "NO" answer in FAQ
- Trade-offs explicit
- Applicability assessed for specific context
